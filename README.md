# Expense Tracker 💜

A simple web-based expense tracker built with HTML, CSS, and JavaScript.

## Features

- Add expenses
- Display expense descriptions and amounts
- Calculate total expenses automatically
- Delete expenses
- Responsive design for mobile devices
- Purple-themed user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## How It Works

Users enter an expense description and amount. The application adds the expense to the list and automatically updates the total amount.

Users can also delete individual expenses.
